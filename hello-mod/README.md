# Hello Command

A minimal Fabric mod for Minecraft 26.3. It adds the `/hello` command, which replies `Hello from your mod!` in chat.

## Run it

1. Install JDK 25 and open this project in IntelliJ IDEA or another Java IDE.
2. From this directory, run `./gradlew runClient`.
3. Start a singleplayer world and enter `/hello` in chat.

The project is based on the [official Fabric example mod](https://github.com/FabricMC/fabric-example-mod/tree/26.3).
